# Smart Group Expense Splitter

This Python script implements a smart group expense splitter that accounts for individuals who do not consume alcoholic beverages. It calculates individual balances and suggests a settlement plan to ensure fair cost distribution.

## Language

`python`

## How to Run

Save the code as `quits_splitter.py` and run it from your terminal using: `python quits_splitter.py`
